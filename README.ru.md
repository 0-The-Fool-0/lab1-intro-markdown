# Работа с Markdown — завершённое упражнение

[English version](README.md)

Этот репозиторий содержит материалы GitHub Skills **Communicate using Markdown**. Упражнение посвящено оформлению документации средствами Markdown непосредственно в GitHub.

## Что отрабатывается

- заголовки и структура документа;
- списки задач и чек-листы;
- примеры кода;
- вставка изображений;
- внесение изменений через pull request и слияние веток.

Папка `.github/steps/` содержит пошаговые инструкции, а `.github/workflows/` — автоматизацию учебного сценария. Их следует сохранять: это часть задания, а не временные файлы сборки.

## Как использовать

1. Сверяйтесь с исходным [README на английском](README.md).
2. Выполняйте шаги в `.github/steps/`.
3. Используйте указанные issue и pull request, чтобы пройти сценарий упражнения.
4. Не изменяйте учебные workflow без необходимости: они проверяют последовательность выполнения задания.

Это учебный репозиторий по Markdown и документации, а не самостоятельное программное приложение.
